# Guide to usage, forgive the brevity

## Teleprompter/python

The Teleprompter could theoretically be used in environments where you have infinite passcode attempts.

You will need Python and NumPy, these are the only requirements.

Teleprompter is meant to be used in terminal.

A more complete Teleprompter may be released in the future.

This should work on any system.

## CPP/C

All of these use standard features, and are shortened versions of the python counterparts.

## Other

This supports any number of digits.

Based on a ruleset consisting of a few rules, and a graph of numbers ranked by likelyhood. 

Works in low-ram environments, should be able to be used in practically any system.

Should be "good enough" for most projects, particuarly automated ones.
